القسم الأول • Current State

1. إيه اللي موجود دلوقتي

  • شات نصي + صوتي: يعمل بتقنية Speech-to-Text المباشرة من المتصفح بالعامية المصرية.
  • محرك الذكاء الاصطناعي: إرسال الأسئلة للـ AI مع System Prompt يجسد شخصية "مستر مينا" وقائمة المعامل العلمية.
  • التوجيه التلقائي للمعمل (Auto-Nav): الموديل يرجع JSON فيه الرد + lab_id ليقوم السيستم بفتح المعمل المناسب وتركيز الضوء عليه تلقائياً.
  • النطق الصوتي اللحظي: تم تسريع الـ TTS ليعمل بـ 0ms Latency مع زر تشغيل مباشر للشرح الحقيقي لمستر مينا.
🔒 متطلب أمان الإنتاج (Production Backend): بناء Backend بسيط (Python FastAPI / Node.js) يستقبل السؤال من الفرونت إند، ويرسله للـ API بمفتاح محفوظ على السيرفر، ويرجع الرد كـ JSON مؤمن.
القسم الثاني • Project Brief

2. إزاي تديله المشروع

سلّمه الحاجات دي كـ Project Brief متكامل:

  • 1. الملف التجريبي والمنصة الشغالة: لمعاينة الفكرة عملياً على http://localhost:8000/.
  • 2. مستند المشروع الأصلي: هوية المشروع، الركائز، والمحتوى العلمي المفصل لمنهجي 1ع و 2ع.
  • 3. هيكل الداتا (JSON Schema): ليعرف المهندس كيف يبني الـ Database والـ Content Pipeline صح من البداية.
  • 4. متطلبات الربط الصوتي: تشغيل الريكوردات الحقيقية واستنساخ ElevenLabs.
  • 5. تحديد بيئة التشغيل: تطبيق ويب تفاعلي عالي الأداء مع دعم حفظ تقدم الطالب ودرجات الكويز.
القسم الثالث • Data & Content Structure

3. إزاي تغذّيه بالمحتوى (Content Structure)

بدل ما تديله المذكرات كـ PDF عشوائي، تم تحويل المعامل إلى بنية JSON Schema معيارية ومنظمة:

{
  "lab_id": "atom",
  "grade": "1ع",
  "title": "مختبر التركيب الذري ومستويات الطاقة",
  "learning_objectives": [
    "يفهم تركيب الذرة والنواة الموجبة",
    "يحسب سعة كل مستوى طاقة بقاعدة 2n²"
  ],
  "explanation_script": "النص الكامل اللي مستر مينا هيشرح بيه الموضوع بصوته وأسلوبه...",
  "key_terms": [
    {"term": "مستوى الطاقة", "definition": "..."},
    {"term": "2n²", "definition": "..."}
  ],
  "audio_files": [
    {"segment": "intro", "file_url": "assets/atom_intro.mp3"},
    {"segment": "level_K", "file_url": "assets/atom_level_k.mp3"}
  ],
  "quiz": [
    {
      "question": "سعة مستوى K كام إلكترون؟",
      "options": ["2", "8", "18", "32"],
      "correct": 0,
      "explanation": "طبقاً للقاعدة 2n² = 2 × (1)² = 2e⁻"
    }
  ]
}

تم إنشاء هذا الهيكل وحفظه بالفعل في ملف labs_content.json لكافة معامل المنهجين!

القسم الرابع • Audio & Voice Mapping

4. إزاي يربط الريكوردات (صوت مستر مينا الحقيقي)

أ) ربط تسجيلات حقيقية جاهزة (استمع إليها الآن):

تسجيل مستر مينا الحقيقي (شرح مندليف وموزلي 2ع): صوت المدرس .ogg
ريكورد توجيهات أسلوب الصوت والتفاعل: voice_note_1.ogg
ريكورد تنظيم تسجيلات الدروس والمذكرات: voice_note_2.ogg

ب) استنساخ الصوت عبر ElevenLabs للأجزاء الجديدة:

  • رفع عينات الصوت النقية لتدريب نموذج الصوت (Instant Voice Clone).
  • توليد الشروحات بالـ Voice ID مع التخزين المسبق (Pre-caching) لضمان سرعة 0ms.

ج) ربط الصوت بحركة الشفاه (Lip-Sync):

  • مزامنة تموجات الصوت مع حركة فم ومجسم مستر مينا 3D لتبدو طبيعية وحيوية.
